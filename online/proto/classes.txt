# What the actors add-on shares (docs/online-wire.md, "The actors add-on").
#
# One row per actor-name pattern, five columns separated by spaces:
#
#   pattern   A name prefix, or *TEXT for a name that contains TEXT. A *TEXT row that matches decides before any
#             prefix row (a Talus's weak point is a part, whatever its body's prefix says); among rows of one kind
#             the longest pattern decides. A name no row matches is not shared.
#   class     map_object world_object enemy boss animal townsperson item projectile puppet device (OW_CLASS_*),
#             or local: never shared, each game keeps its own.
#   id        map: placed by the map, known by its map instance id. creator: made at run time, known by its
#             creator's account and counter. map|creator: either. leader: id-less, one game leads (the herd rule).
#             - for local rows.
#   comps     The components its states carry, from anim life gear mind ride glide aim held scale, joined by
#             commas; - for none.
#   rules     Owner rules beyond the common ones, joined by commas; - for none:
#               still        keeps its owner while it has not moved 1 m in 5 s (rule 5)
#               fight        stays with its owner while it was hit in the last 10 s (rule 7)
#               lock         a boss: stays with its owner while a player is near (rule 7)
#               part=P|Q     follows the nearest record within 60 m whose name starts with P or Q (rule 8)
#               held         follows the enemy within 12 m that holds or throws it (rule 8)
#               fixed        never changes owner (rule 8)
#               quest        once owned, moves only when its owner leaves or a player holds it (rule 8)
#               cluster      a contraption part: parts within 6 m of one another are decided as one (rule 11)
#               core         what makes a cluster a vehicle (rule 11)
#               take         a take-once thing: the first game to take it gets it (take, taken)
#
# Edit this file, then run python tools/gen_classes.py: tests/net_proto_check.py fails while ow_classes_data.h
# differs. The rows come from the old port's sharing table and owner rules; none has been shown on two screens of this
# port yet, and a row that misbehaves in a round is made local until it is fixed.
